# Adrobot для Keitaro

Локальное веб-приложение на FastAPI, SQLAlchemy 2 и SQLite. Создаёт кампанию с геофильтром и позволяет редактировать привязки офферов в уже существующих потоках. Интерфейс на русском языке, сборка фронтенда не требуется.

## Установка и запуск

Проверено с Python 3.12. Выполняйте команды из корня репозитория.

```bash
git clone https://github.com/Keymax32/adrobot-keitaro.git
cd adrobot-keitaro
python -m venv .venv
```

Активируйте окружение и создайте локальный файл настроек.

| Система | Активация | Копирование настроек |
| --- | --- | --- |
| Windows PowerShell | `.\.venv\Scripts\Activate.ps1` | `Copy-Item .env.example .env` |
| Linux / macOS | `source .venv/bin/activate` | `cp .env.example .env` |

В `.env` задайте `KEITARO_URL` — HTTPS-адрес трекера без `/admin`, и `KEITARO_API_KEY` — ключ из раздела «Профиль → API ключи». Ключ использует только сервер. Для проверки нужны права на чтение офферов, доменов, источников и групп, создание кампаний и изменение потоков. [Документация Admin API](https://admin-api.docs.keitaro.io/)

```bash
python -m pip install -r requirements.txt
python -m alembic upgrade head
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [интерфейс](http://127.0.0.1:8000) или [Swagger UI](http://127.0.0.1:8000/docs). Сервис рассчитан на локальную работу одного оператора. Используйте отдельный файл SQLite для каждого трекера.

## Создание кампании

1. Откройте «Новая кампания». Введите название, двухбуквенный код страны и ID оффера.
2. Выберите домен, группу и источник из справочников Keitaro. Нажмите «Создать кампанию». Префикс по умолчанию — `test_kappes_`. Его можно изменить через `CAMPAIGN_PREFIX`.
3. В редакторе откроется новая кампания. Первый поток проверяет страну и отправляет совпавшие клики на Google. Поток по умолчанию отправляет остальные клики на выбранный оффер с долей 100%.

Сервер создаёт кампанию выключенной и активирует её после создания обоих потоков. Если настройка прервётся после получения ID кампании, интерфейс покажет этот ID. Проверьте состояние кампании в Keitaro перед повторной попыткой.

## Редактирование

| Действие | Результат |
| --- | --- |
| Открыть по ID | При первом открытии загружает потоки. При повторном открытии возвращает сохранённое локальное состояние, включая черновики. |
| Загрузить из Keitaro | Обновляет потоки и доли. Ранее известные офферы, исчезнувшие из потока, переходят в локальный архив. Перед загрузкой опубликуйте или отмените черновики. |
| Найти → Добавить | Ищет оффер по ID или названию. Добавляет привязку в черновик выбранного потока. |
| Удалить / Вернуть | Архивирует или восстанавливает привязку. Архивная строка серая, её доля равна 0%. |
| Закрепить / Открепить | Фиксирует текущую долю активного оффера или возвращает его в общий пересчёт. |
| Отменить | Возвращает опубликованный снимок потока, включая состав, доли и закрепления. |
| Опубликовать | Сверяет состав и доли с Keitaro и отправляет только список офферов изменённого потока. При конфликте черновик остаётся доступен. |

Жёлтый фон помечает черновик. Изменение одного потока не публикует соседние. Потоки с редиректом отображаются одной строкой. Закрепления и архив хранятся локально и сохраняются после перезапуска.

После добавления, удаления или восстановления оффера свободный остаток делится поровну между активными незакреплёнными офферами. Первые по порядку получают остаток от целочисленного деления. Например, при закреплённых 25% и двух свободных офферах доли равны 25%, 38% и 37%. Если ограничения не позволяют набрать 100%, операция вернёт ошибку и сохранит прежний черновик. При удалении последней привязки в Keitaro публикуется пустой список.

## Миграции и тесты

`python -m alembic current` показывает текущую ревизию. После обновления кода примените `python -m alembic upgrade head`. База по умолчанию находится в `adrobot.db` в корне проекта. Для резервной копии остановите сервис и скопируйте файл. Откат начальной миграции командой `python -m alembic downgrade base` удаляет локальные снимки, закрепления и черновики.

```bash
python -m pip install pytest
python -m pytest -q
```

Тесты используют временную SQLite и подмену ответов Keitaro. Они проверяют округление, закрепления, архив, восстановление, отмену черновика, публикацию и конфликт при внешнем редактировании.
